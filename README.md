# Stochastic-Calculus-for-Finance-II-Continuous-Time-Models-
A self-study notebook on Stochastic Calculus for Finance II by Steven Shreve. Covers measure-theoretic probability, Brownian motion, Itô calculus, and risk-neutral pricing. Each chapter is split into a theory section (definitions, theorems, lemmas, remarks) and an exercise section (solutions with supporting Python code and simulations).
